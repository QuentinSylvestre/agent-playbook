What we learned the hard way

“

A report of a check is not the check.

So

Ask for the scan or the photo, not the summary.

“

A posted rule is not a rule people follow.

So

Build the rule into the workstation itself.

“

Honour-system sign-offs get skipped.

So

Make every gate a scan that cannot be bypassed.

“

A metric must be audited itself.

So

Otherwise its blind spots read as "no problem".
