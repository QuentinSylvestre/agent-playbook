# Core Logo Exploration Prompt

Use when exploring first-round identity concepts.

```txt
Design a set of distinct identity concepts for [PROJECT].
Product: [ONE_SENTENCE_PRODUCT].
Audience: [AUDIENCE].
Brand tension: [BRAND_TENSION].
Category strategy: [ALIGN/BEND/BREAK] [CATEGORY].
Explore both semantic/iconic and abstract/signature directions.
Vary metaphor, silhouette, material/rendering, and color moderately.
Prioritize distinctive, ownable marks with strong silhouettes and small-size potential.
Avoid generic startup logos, default gradient blobs, lazy first-letter marks, excessive micro-detail, and concepts that only work because of glow.
Return 10 concepts in a clean comparison grid. Each concept should be visually distinct and suitable as the seed for a full app-icon/logo identity system.
```
