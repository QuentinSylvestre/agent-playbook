# Critique Rubric

Score only shortlisted concepts unless the user asks for full scoring.

Baseline criteria:

| Criterion | What to evaluate |
|---|---|
| Distinctiveness | Could this become recognizable, or is it generic? |
| Semantic fit | Does it communicate the product, values, or metaphor? |
| Small-size readability | Does it survive favicon/tray/app-icon sizes? |
| Silhouette strength | Does it work in monochrome/simplified form? |
| Polish potential | Can it become premium without clutter? |
| Asset-system flexibility | Can it support mark, icon, wordmark, favicon, states? |
| Brand longevity | Will it still feel credible after trends shift? |

Adapt weights based on project type. A developer tool, wellness app, AI assistant, and invoice SPA do not need identical weightings.

Use this format:

```md
| Concept | Distinctive | Fit | Small-size | Silhouette | Polish | System | Longevity | Verdict |
|---|---:|---:|---:|---:|---:|---:|---:|---|
```

Call out concepts that are beautiful but not ownable/distinctive enough. Offer rescue paths when possible.
